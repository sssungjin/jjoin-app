# jjoin

### 주요 기능

1. **사용자 앱 (Flutter)**
    - 동아리 일정 확인
    - 동아리 검색 및 가입 신청
    - 마이페이지 관리 (프로필, 가입 동아리 목록 등)
2. **관리자 웹 (React)**
    - 동아리 관리 (회원 승인, 일정 등록)
    - 서비스 관리자: 동아리 생성 및 삭제 권한
    - 데이터 분석 기능 제공 (사용자 통계 등)
3. **서버 (Spring Boot)**
    - 사용자 인증 및 권한 관리 (JWT)
    - REST API 제공 (동아리 관리, 회원 관리 등)
    - 데이터베이스 연동 (MySQL)

## 기술 스택

- **백엔드**
    - Framework: Spring Boot
    - Database: MySQL
    - 인증: JWT (JSON Web Token)
- **프론트엔드**
    - 웹 (관리자): React
    - 앱 (사용자): Flutter
